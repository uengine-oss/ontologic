# 온보딩 시연 영상 — 시스템 등록부터 보상까지

`온보딩-질의-커맨드-보상-시연.mp4` (7분 14초, 1920×1080, 23장면) · 자막 `.srt`

시스템 등록(설비보전 CMMS 를 마법사로 — OpenAPI 업로드·API 키·연결 테스트·수동 API) → 설비 대장 문서 + 의도 ·
골든 퀘스천 · 골든 커맨드로 **실제 구축 에이전트**가 온톨로지와 3단계 액션(단계별 보상)을 만들고 dry-run 검증 →
질의 → 커맨드 → 공장장 승인 → 실행 → 「취소해 줘」 역순 보상 → 생산계획 장애 시 자동 보상.

## 재생성

```bash
./run.sh          # 초기화(그래프 비움·CMMS 미등록·새 Studio 저장소) → Studio 재기동 → 캡처 → 합성
FROM=15 node capture.mjs   # 구축된 상태에서 15번 장면부터만 다시 (뒷부분 시험용)
```

캡처는 장면마다 화면 내용을 검사하고 실패하면 `FAIL-*.png` 를 남기고 멈춘다. 구축 보고서에 미검증이 남으면
채팅으로 한 번 「검증을 마저 해 달라」고 요청한다(영상에는 나오지 않는다).

- 새 스키마 이름이 `[대상 스키마]` 로 넘어가 에이전트가 멈춤 → `[새 스키마 이름]` 분리
- 구축 지시문에 업로드 문서 목록이 없음 → `[업로드 문서]`
- 정책 역할 이름을 지어냄(`operator`) → `KINETIC_ROLE_CATALOG` 로 `[실행 역할]` 제공
